# Dataset Information

## Selected Dataset: APTOS 2019 Blindness Detection

### Why APTOS 2019?

| Criterion | Details |
|-----------|---------|
| **Full Name** | Asia Pacific Tele-Ophthalmology Society 2019 Blindness Detection |
| **Source** | Kaggle Competition — https://www.kaggle.com/competitions/aptos2019-blindness-detection |
| **Images** | 3,662 training retinal images (labelled), 1,928 test images (unlabelled) |
| **Format** | JPEG, variable resolution |
| **Labels** | 5-class ordinal (0–4) |
| **License** | Kaggle Competition Rules — free for academic/non-commercial research |
| **Documentation** | Excellent — used in 1000s of published papers |
| **Reproducibility** | Widely used benchmark |

### DR Severity Labels

| Label | Class | Description |
|-------|-------|-------------|
| 0 | No DR | No signs of diabetic retinopathy |
| 1 | Mild | Microaneurysms only |
| 2 | Moderate | More than microaneurysms but less than severe |
| 3 | Severe | Severe NPDR — 4-2-1 rule |
| 4 | Proliferative DR | New vessel formation |

### Dataset Statistics (Training Set)

| Class | Count | Percentage |
|-------|-------|-----------|
| 0 — No DR | ~1805 | ~49.3% |
| 1 — Mild | ~370 | ~10.1% |
| 2 — Moderate | ~999 | ~27.3% |
| 3 — Severe | ~193 | ~5.3% |
| 4 — Proliferative DR | ~295 | ~8.1% |

Note: Significant class imbalance — handled via weighted cross-entropy loss.

### Access Instructions

**IMPORTANT:** Kaggle requires a free account and acceptance of competition rules.

1. Create a free Kaggle account at https://www.kaggle.com
2. Go to: https://www.kaggle.com/competitions/aptos2019-blindness-detection
3. Click "Join Competition" and accept the rules
4. Generate an API token: https://www.kaggle.com/settings → API → Create New Token
5. Save the `kaggle.json` to `~/.kaggle/kaggle.json` (or set env vars)
6. Run: `python scripts/setup_dataset.py`

### Alternative Datasets

If APTOS 2019 is unavailable, the codebase also supports:

| Dataset | Source | Notes |
|---------|--------|-------|
| EyePACS | https://www.kaggle.com/c/diabetic-retinopathy-detection | 35,000 images, same 5-class labels |
| IDRiD | https://idrid.grand-challenge.org/ | 516 images, pixel-level lesion annotations |
| Messidor-2 | https://www.adcis.net/en/third-party/messidor2/ | 1,748 images, French research dataset |

### What This Dataset Does NOT Contain

- Real patient EHR records
- Patient demographics
- Clinical history
- Laboratory results

The EHR module uses **synthetic/demo data only**. This is clearly marked throughout the application.

### EHR Module

See `data/ehr/ehr_schema.md` for the synthetic EHR feature schema.
Synthetic EHR records are generated by `scripts/generate_synthetic_ehr.py`.

**NEVER present synthetic EHR data as real patient data.**
